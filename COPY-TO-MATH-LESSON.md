# EXPORT ONLY — Algonova Math

Folder ini **bukan** bagian produk Kindora.

Copy seluruh isi folder ini ke repo `kindoradeveloper/math-lesson`, lalu hapus folder export ini dari kindoraweb.

## Cara (Windows)

1. Download folder `exports/algonova-math/` dari branch `cursor/algonova-math-export-3594`
2. Copy isinya ke `C:\Users\user\math-lesson\` (timpa README lama boleh)
3. Di CMD:

```bat
cd C:\Users\user\math-lesson
git add -A
git commit -m "feat: initial Algonova Math app"
git push
```

4. Minta agent di repo **math-lesson** lanjut polish (jangan kerja di kindoraweb).
